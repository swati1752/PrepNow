Overview

A clean guide covering five fundamental sorting algorithms in Java. Each algorithm features its core crux logic, complete Java code implementation, and computational complexity breakdown.

1. Bubble Sort

O(n²) Average

Crux Logic

Imagine shaking a carbonated drink—the biggest bubbles rise to the top. Bubble sort repeatedly compares adjacent elements and swaps them if they are in the wrong order. After each complete pass through the array, the largest remaining element "bubbles up" to its correct position at the end.

Java Implementation

public static void bubbleSort(int[] arr) {
    int n = arr.length;
    boolean swapped;
    for (int i = 0; i < n - 1; i++) {
        swapped = false;
        for (int j = 0; j < n - i - 1; j++) {
            if (arr[j] > arr[j + 1]) {
                // Swap arr[j] and arr[j+1]
                int temp = arr[j];
                arr[j] = arr[j + 1];
                arr[j + 1] = temp;
                swapped = true;
            }
        }
        // Optimization: If no swaps occurred, the array is already sorted
        if (!swapped) break;
    }
}

2. Selection Sort

O(n²) Average

Crux Logic

Think of sorting playing cards in your hand by scanning the whole deck to find the absolute smallest card, placing it first, then scanning the rest to find the next smallest, and so on. It divides the array into a sorted region (left) and an unsorted region (right), picking the minimum element from the unsorted part to grow the sorted part.

Java Implementation

public static void selectionSort(int[] arr) {
    int n = arr.length;
    for (int i = 0; i < n - 1; i++) {
        int minIndex = i;
        for (int j = i + 1; j < n; j++) {
            if (arr[j] < arr[minIndex]) {
                minIndex = j;
            }
        }
        // Swap the found minimum element with the first element of the unsorted part
        int temp = arr[minIndex];
        arr[minIndex] = arr[i];
        arr[i] = temp;
    }
}

3. Insertion Sort

O(n²) Average

Crux Logic

This mimics how most people sort a hand of cards in real life. You take one card at a time, look at the sorted cards you're already holding, shift them over if they are larger, and insert the new card into its correct spot.

Java Implementation

public static void insertionSort(int[] arr) {
    int n = arr.length;
    for (int i = 1; i < n; i++) {
        int key = arr[i];
        int j = i - 1;
        
        // Shift elements of the sorted segment that are greater than key
        // to one position ahead of their current position
        while (j >= 0 && arr[j] > key) {
            arr[j + 1] = arr[j];
            j--;
        }
        arr[j + 1] = key;
    }
}

4. Quick Sort

O(n log n) Average

Crux Logic

Divide and Conquer. Pick an element called a pivot. Rearrange (partition) the array so that all numbers smaller than the pivot sit to its left, and all numbers larger sit to its right. Then, recursively apply the same process to the left and right sub-arrays.

Java Implementation

public static void quickSort(int[] arr, int low, int high) {
    if (low < high) {
        int pi = partition(arr, low, high);
        quickSort(arr, low, pi - 1);  // Before pivot
        quickSort(arr, pi + 1, high); // After pivot
    }
}

private static int partition(int[] arr, int low, int high) {
    int pivot = arr[high]; // Choosing the last element as pivot
    int i = (low - 1);
    
    for (int j = low; j < high; j++) {
        if (arr[j] < pivot) {
            i++;
            int temp = arr[i];
            arr[i] = arr[j];
            arr[j] = temp;
        }
    }
    // Place pivot in its correct position
    int temp = arr[i + 1];
    arr[i + 1] = arr[high];
    arr[high] = temp;
    
    return i + 1;
}

5. Merge Sort

O(n log n) Average

Crux Logic

Divide and Conquer via splitting and merging. Recursively split the array in half down to single-element arrays (which are inherently sorted), and then merge those small sorted halves back together in order to build up a fully sorted array.

Java Implementation

public static void mergeSort(int[] arr, int left, int right) {
    if (left < right) {
        int mid = left + (right - left) / 2;
        
        // Sort first and second halves
        mergeSort(arr, left, mid);
        mergeSort(arr, mid + 1, right);
        
        // Merge the sorted halves
        merge(arr, left, mid, right);
    }
}

private static void merge(int[] arr, int left, int mid, int right) {
    int n1 = mid - left + 1;
    int n2 = right - mid;

    int[] L = new int[n1];
    int[] R = new int[n2];

    for (int i = 0; i < n1; ++i) L[i] = arr[left + i];
    for (int j = 0; j < n2; ++j) R[j] = arr[mid + 1 + j];

    int i = 0, j = 0, k = left;
    while (i < n1 && j < n2) {
        if (L[i] <= R[j]) {
            arr[k++] = L[i++];
        } else {
            arr[k++] = R[j++];
        }
    }

    while (i < n1) arr[k++] = L[i++];
    while (j < n2) arr[k++] = R[j++];
}
