Module 1: Core Spring Architecture & GraalVM Native

Spring Triangle, Lifecycles, Configuration, DevTools, and Ahead-Of-Time compilation

Dependency Injection (DI)

Inverts object creation control. Spring Container injects dependencies, reducing coupling and increasing testability.

Portable Service Abstraction

Abstracts low-level vendor code (JPA, Transactions, JMS) behind uniform, portable API abstractions.

Aspect-Oriented Programming

Decouples cross-cutting concerns (logging, security, transaction management) from core business logic.

Bean Lifecycle Hooks Example 
@Component
public class DatabaseManager implements InitializingBean, DisposableBean {

    // 1. Lifecycle via Annotations (Recommended)
    @PostConstruct
    public void postConstruct() {
        System.out.println("Step 1: @PostConstruct executed after properties set.");
    }

    // 2. Lifecycle via Interface
    @Override
    public void afterPropertiesSet() throws Exception {
        System.out.println("Step 2: InitializingBean interface validation executed.");
    }

    @PreDestroy
    public void preDestroy() {
        System.out.println("Step 3: @PreDestroy executed before shutdown.");
    }

    @Override
    public void destroy() throws Exception {
        System.out.println("Step 4: DisposableBean destroy cleanup executed.");
    }
}

GraalVM Native Image vs JIT Compilation

Native Compilation: Uses Ahead-Of-Time (AOT) compilation to produce a standalone executable binary (~90 MB) that requires no host JRE. Bundles the app code, Netty/Tomcat runtime, and ORM components natively.

Standard Executable JAR (JIT): `./mvnw clean package`
GraalVM Native Binary (AOT): `./mvnw -DskipTests -Pnative native:compile`

Module 2: Spring AI & Vector Search

LLM Integration, Vector Databases, Tool Calling, and RAG Architecture

Core Terminology

  • Context Window: The token capacity budget for input prompts and model responses.
  • Embeddings: High-dimensional floating-point vectors representing semantic meaning.
  • Cosine Similarity: Mathematical metric evaluating directional vector alignment to quantify semantic relevance.

RAG & Tool Calling Architecture

  • RAG (Retrieval-Augmented Generation): Retrieves domain data from a Vector DB to enrich the LLM context prompt before response generation.
  • Tool Calling: Empowers LLMs to invoke external Java services, APIs, and business databases dynamically.

Module 3: Spring Batch & High-Volume ETL

Extraction, Transformation, Loading, Chunking, and Distributed Scalability

Chunk-Based Processing

Processes items in chunks (`ItemReader` → `ItemProcessor` → `ItemWriter`). Each chunk runs in an independent transaction. If an item fails, the entire chunk transaction rolls back to ensure strict data integrity.

Job Parameters & RunIdIncrementer

Spring Batch uses Job Parameters to create unique execution keys to prevent accidental duplicate runs. In development, RunIdIncrementer generates monotonic parameter keys to allow re-runs.

GraphQL Architecture

  • 3 Verbs: Queries, Mutations, Subscriptions.
  • Schema First: Upfront type definitions.
  • Batch Mapping: Bypasses N+1 queries by fetching child relationships in bulk via `@BatchMapping`.

gRPC & Protobuf

  • Transport: HTTP/2 multiplexing.
  • Protocol Buffers: Efficient binary wire format.
  • Numeric Tags: Fields assigned IDs (e.g. `int32 id = 1`) for safe evolution.

REST & Virtual Threads

  • HATEOAS: Richardson Maturity Model Level 3 (Hypermedia state links).
  • Virtual Threads: Java Project Loom lightweight threads optimal for I/O blocking calls.

Module 5: Messaging Systems (Kafka & AMQP)

Apache Kafka Components, Wire Security, Consumer Groups, and Messaging Projects

Apache Kafka Architecture

  • Broker & Topic: Server nodes storing named data streams divided into physical partitions.
  • Consumer Group: Collection of consumers sharing a `group.id` to balance partition reads without duplicates.
  • Offset & Wire Protocol: Sequential IDs tracking progress over Kafka's custom binary TCP protocol.

Serialization & Trusted Packages

Kafka blocks arbitrary JSON object deserialization by default for security. Configure explicit trusted packages in application properties: 

spring.kafka.consumer.properties.spring.json.trusted.packages=com.example.dto,com.example.events

Spring Messaging Framework Ecosystem

Spring for Apache Kafka

Provides `KafkaTemplate` and `@KafkaListener` annotations.

Spring AMQP

RabbitMQ abstraction implementing Advanced Message Queuing Protocol.

Spring for Apache Pulsar

Unified messaging support for Pulsar streaming topics.
